# Changuito — Branding

Kit en `apps/branding/` (hermano de `apps/web` y `apps/landing`). Assets y manuals para la landing (www.changuito.me) y el lanzamiento social.

## Estructura

| Carpeta | Contenido |
|---------|-----------|
| `manuals/` | Manual de marca (MD + PDF) |
| `logo/` | Wordmark, lockups, isotipo, Sol de Mayo |
| `mascot/` | Poses locked (idle, corriendo, esperando, comparando, lleno) |
| `_discarded/` | Pose éxito — no aprobada, no usar en marketing |
| `pattern/` | Patrón mate-pan + iconos sueltos |
| `motion/` | GIFs de animación aprobados |
| `product/` | Mocks de perk beta: leche con proteína (botella canónica + brick alternativo). No es un SKU lácteo. |
| `social/linkedin/` | Banners, cuadrado, infografía, carrusel |
| `social/x-twitter/` | Banner y cuadrado |
| `social/instagram/` | Feed, story, reel, infografía, carrusel |
| `copy/` | Copys LinkedIn / X / Instagram / ads |
| `tokens/` | Tokens / helpers Next |

## Reglas rápidas

- Header de piezas: solo **wordmark** (sin mascota arriba).
- No regenerar mascota con IA: reusar estos PNG.
- Mocks de `product/`: la botella (`leche-proteina-changuito-botella.png`) es la canónica — PROTEÍNA **∞g** (chiste nerd), wordmark + mascota, Edición beta. El brick Tetra Pak (`leche-proteina-changuito-brick.png`) es el alternativo. Van a pauta Meta y al perk de beta; no son un lácteo real de góndola. Los bytes son los aprobados: no regenerarlos.
- La pose éxito (destellos + medalla de girasol) no está aprobada. No usarla en la landing ni en marketing de consumo. Vive en `_discarded/`.
- No microcopy de devolución en consumer.
- Frases: LinkedIn *Pedí el súper inteligente* · X/Meta *Armá el súper sin pensar* · IG *Changuito te lo hace fácil*.
